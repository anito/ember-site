# oryzo.ai: what was observed (read via curl on 2026-10-19)

Only the static HTML and the page script were read. **No scroll film was watched**: the order of the stages, the camera moves and the look of the animations are NOT known from this. Treat this as a copy deck and a technology hint, and ask the user (or look at screenshots) for the motion.
